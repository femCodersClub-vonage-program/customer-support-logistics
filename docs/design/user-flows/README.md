# User Flows — Customer Support Logistics

This folder documents how delivery incidents are handled by customers, support agents and drivers.

## Roles

- **Customer:** Reports incidents, follows their progress and joins mediation calls when needed.
- **Agent:** Reviews incidents, contacts drivers and manages resolutions.
- **Driver:** Communicates through SMS and phone calls. No application is required.

## Documentation

- [Customer flow](customer.md)
- [Agent flow](agent.md)
- [Driver flow](driver.md)

## Ticket states

- `open`: Incident reported.
- `notified`: Driver notification initiated.
- `in_mediation`: Mediation in progress.
- `resolved`: Incident resolved.
- `escalated`: Further handling required.
